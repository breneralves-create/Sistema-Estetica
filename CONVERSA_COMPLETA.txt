Tem sim! No **VS Code**, existem alguns atalhos que "limpam" a tela e deixam o código (ou o texto) ocupando quase todo o monitor, o que é ótimo para prints.

Aqui estão os melhores comandos para você usar:

1.  **Modo Zen (Zen Mode):** Aperte **`Ctrl + K`** e depois a letra **`Z`**. Isso vai esconder tudo (barra lateral, abas, menus) e deixar só o texto centralizado na tela cheia. Para sair, é só apertar `Esc` duas vezes.

3.  **Esconder o Painel de Baixo (Terminal):** Aperte **`Ctrl + J`**.
4.  **Tela Cheia:** Aperte **`F11`**.
5.  **Diminuir o Zoom:** Se o texto for muito grande e você quiser que caiba mais coisa no print, aperte **`Ctrl + -`** (sinal de menos) algumas vezes. Para aumentar de volta, use `Ctrl + +`.

Se você usar o **Modo Zen (`Ctrl + K` e depois `Z`)**, vai conseguir o print mais "limpo" e profissional possível! 📸🚀
